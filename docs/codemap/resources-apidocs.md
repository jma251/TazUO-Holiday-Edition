## Timing

- **Compile time**: the three `.Designer.cs` files are regenerated by Visual Studio / ResGen from their `.resx` siblings; the `.resx` are `EmbeddedResource` in the client assembly (`ClassicUO.Client.csproj:69-81`). `Loader.cs`'s two method bodies are produced by the `EmbedResourceCSharp` 1.1.3 source generator (`Directory.Build.props:45`) reading `src/ClassicUO.Client/cuologo.png` and `src/ClassicUO.Client/game-background.png`.
- **First access, then cached forever**: `ResourceManager` construction, once per resource class, on the first property read (typically during gump construction or the first packet that formats a message).
- **Per gump build / per packet / per input**: every property read is a `ResourceManager.GetString` — a dictionary hit after the culture's ResourceSet is loaded, but it is a real lookup, not a constant. Highest-density call sites are gump constructors (`WorldMapGump.cs` 52 reads, `HouseCustomizationGump.cs` 45, `StatusGump.cs` 41) and message formatting (`ChatManager.cs` 41 `ResGeneral.` reads, `PacketHandlers.cs` 12).
- **Once at startup**: `Loader.GetBackgroundImage()` at `GameController.cs:226`, immediately before `loadResourceAssets.Wait(10000)` and `SetScene(new LoginScene())`. Called on the main/init thread, allocates a `byte[]` copy via `.ToArray()` and builds a `Texture2D` from a `MemoryStream`.
- **Never at runtime**: all of `APIToMarkdown`. Its `AfterTargets="Build"` invocation is **commented out** in `ClassicUO.Client.csproj:129-132`; the project is still in `ClassicUO.sln:82`, so it compiles but is only run by hand (`dotnet run --project src/APIToMarkdown/APIToMarkdown.csproj <docsDir> <files...>`).
- No timers, no per-frame work, no tick rate anywhere in this partition.

## Hazards

- `Resources/ResGumps.Designer.cs:3686` — `AutoAvoidObstacules` is a hand-written property inserted into an `<auto-generated>` file (no `///` doc comment, different brace style). The key `AutoAvoidObstacules` is **not present in `ResGumps.resx`**, so `ResourceManager.GetString` returns `null`. Nothing reads it (the options gump uses `Language.Instance.GetGeneral.AutoAvoidObstacules`, `ModernOptionsGump.cs:3391`). Regenerating the designer from the `.resx` deletes this property.
- `Resources/ResGumps.Designer.cs:41-46` (and `ResGeneral.Designer.cs:41`, `ResErrorMessages.Designer.cs:41`) — check-then-assign on a static without a lock; two threads reaching a resource class first can each build a `ResourceManager`.
- `Resources/ResGumps.Designer.cs:54-61` — `Culture` setter is dead: no assignment exists in the repo, while `ResGumps.ChangingLanguageNeedsRestartToTakeEffect` (:579) advertises a language switch. Language switching in this fork is `Configuration/Language.cs` (JSON), which does not feed `resourceCulture`.
- `Resources/Loader.cs:12` — `GetCuoLogo()` has no callers; the PNG is still embedded in the assembly.
- `GameController.cs:226` (call into `Loader.cs:15`) — `.ToArray()` copies the embedded span onto the heap on the startup path; the `ReadOnlySpan<byte>` overload of the API is discarded.
- `APIToMarkdown/Program.cs:9,22` — `isMainAPI` is static mutable and set inside the class loop; any parallelisation or reentry corrupts formatting of every subsequent class.
- `APIToMarkdown/Program.cs:229-241` — enum value inference: `byte last = 0`, `var value = last += 1` mutates `last` before the explicit-value branch, and `byte.TryParse` fails silently for values > 255, negatives, hex, or `1 << n` expressions, leaving `value` as the incremented counter. Emitted `API.py` enum numbers can disagree with the C# enum.
- `APIToMarkdown/Program.cs:418` and `:436` — `sb.Remove(sb.Length - 2, 2)` unconditionally trims two chars; safe only because both call sites early-return on `parameters.Count == 0`.
- `APIToMarkdown/Program.cs:451-453` — `uint.MaxValue`, `ushort.MaxValue` and `int.MinValue` all map to the literal Python default `1337`; the sentinel is not the real value.
- `APIToMarkdown/Program.cs:446` — `defaultValue.Replace("f", "")` strips *every* `f`, not just a float suffix, for any default that is not the string `false` (e.g. an identifier default containing `f`).
- `APIToMarkdown/Program.cs:609-610` — `.md` files are written with `WriteAllText` (overwrite) but `API.py` is `AppendAllText` across all input files; the file is deleted once up front at `:586-588`, so a partially failed run leaves a truncated/duplicated `API.py`.
- `APIToMarkdown/Program.cs:23` — `classesDict.TryAdd(className, …)`: two classes with the same identifier in one file (or nested classes) share one builder and get concatenated into a single `.md`.
- `APIToMarkdown/Program.cs:603` — `string path = Path.GetDirectoryName(filePath)!;` is assigned and never used.
- `APIToMarkdown/Program.cs:163` — hardcoded skip of the field named `QueuedPythonActions`; a rename in `API.cs` silently reintroduces it into the public docs.
